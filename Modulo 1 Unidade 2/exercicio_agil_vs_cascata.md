# Metodologias de Desenvolvimento

## Atividade Avaliativa

Produzir uma tabela comparativa entre as metodologias **Ágil** e **Cascata (Waterfall)**, indicando:

- Como os testes acontecem em cada modelo;
- Vantagens e limitações.

---

# Tabela Comparativa

| Critério | Ágil | Cascata (Waterfall) |
|----------|-------|---------------------|
| **Modelo de desenvolvimento** | Iterativo e incremental, com entregas frequentes. | Sequencial, onde cada fase é concluída antes da próxima. |
| **Como os testes acontecem** | Os testes são realizados continuamente durante todo o desenvolvimento, a cada sprint. A equipe de testes trabalha em conjunto com os desenvolvedores, identificando e corrigindo falhas rapidamente. | Os testes acontecem apenas após a conclusão do desenvolvimento. Primeiro o sistema é implementado e, em seguida, inicia-se a fase de testes. |
| **Participação do cliente** | Alta, com feedback constante durante todo o projeto. | Baixa, geralmente apenas na definição dos requisitos e na entrega final. |
| **Mudanças nos requisitos** | São facilmente incorporadas durante o desenvolvimento. | São difíceis e possuem alto custo quando o projeto já está em andamento. |

---

# Vantagens x Limitações

## Ágil

### Vantagens

- Testes contínuos durante todo o desenvolvimento.
- Identificação rápida de falhas.
- Entregas frequentes de novas funcionalidades.
- Facilidade para adaptar mudanças nos requisitos.
- Maior interação entre cliente e equipe.

### Limitações

- Exige comunicação constante entre todos os envolvidos.
- Pode ser mais difícil estimar prazo e custo total do projeto.
- Necessita de participação ativa do cliente.

---

## Cascata (Waterfall)

### Vantagens

- Planejamento simples e bem estruturado.
- Documentação detalhada.
- Ideal para projetos com requisitos bem definidos e estáveis.
- Fácil acompanhamento das etapas.

### Limitações

- Os erros costumam ser identificados apenas no final do desenvolvimento.
- Alterações durante o projeto são caras e difíceis.
- O cliente visualiza o produto somente próximo da entrega final.

---

# Conclusão

## Ágil

Os testes são realizados continuamente durante todo o ciclo de desenvolvimento. Isso permite identificar defeitos rapidamente, reduzir custos com correções e entregar software de maior qualidade.

## Cascata

Os testes são executados somente após a implementação completa do sistema. Como consequência, falhas podem ser descobertas tardiamente, aumentando o esforço e o custo das correções.

---

# Resumo

| Item | Ágil | Cascata |
|------|-------|----------|
| **Quando os testes acontecem?** | Durante todo o desenvolvimento. | Após a implementação completa. |
| **Flexibilidade** | Alta | Baixa |
| **Correção de erros** | Rápida | Mais lenta e custosa |
| **Participação do cliente** | Contínua | Limitada |
| **Melhor indicação** | Projetos com mudanças frequentes | Projetos com requisitos fixos |
